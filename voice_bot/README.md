# Voice Bot

Телеграм-бот, который принимает голосовые сообщения, загружает их на удалённый сервер по HTTP без сохранения на диск и отвечает одним из заранее подготовленных сообщений. Метаданные о голосовых сохраняются в локальной базе SQLite.

## Запуск

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Установите переменные окружения:

- `TELEGRAM_BOT_TOKEN` – токен телеграм-бота.
- `VOICE_UPLOAD_URL` – адрес сервера, принимающего голосовые файлы.

3. Запустите бота:

```bash
python bot.py
```
